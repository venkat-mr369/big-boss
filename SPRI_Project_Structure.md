# SPRI Platform — Project & Folder Structure Reference

Extracted from the 5 uploaded zip files (`common-library-dev.zip`, `patient-service-dev.zip`, `spri-client-dev.zip`, `survey-service-dev.zip`, `temp-legacy-data-import-dev.zip`). `node_modules`, `.git`, and `.terraform` are excluded; deeply repetitive folders (Prisma `migrations/`, migration `sql/` parts, `__pycache__`) are collapsed to a folder/file count for readability.

## Repo Summary

| Project | Type | Purpose (from package.json / contents) | Files (excl. node_modules) |
|---|---|---|---|
| **common-library-dev** | NestJS library (`@steadman-philippon-research-institute/common-library`) | Shared Prisma schema/migrations, AWS Secrets Manager, logging/OTel, notifications, decorators/guards used by the other services | 366 |
| **patient-service-dev** | NestJS microservice | Patient Service (NestJS 10) — patients, appointments, facilities, physicians, schedule, QR code, multi-tenant | 229 |
| **survey-service-dev** | NestJS microservice | Survey Service — automated/clinician/patient surveys, form templates, Formsite/Formsort integrations, PDF (ModMed) generation | 188 |
| **spri-client-dev** | Angular app (`spri-angular`) | SPRI Clinical Web Console front-end — patient forms, surgery modules (ankle/foot), PRO scoring, navigation, dashboards | 1041 |
| **temp-legacy-data-import-dev** | Python + Terraform ETL project | One-off legacy data migration (35-part SQL migration scripts, Terraform infra, test CSV data) | 184 |

Note: several core services depend on `@steadman-philippon-research-institute/common-library` as a shared package (Prisma schema, AWS, logging, auth). This matches the "SPRI Platform Modernization" data pipeline / clinical web console discovery reports also included in your uploads.
